# AgentHub

AgentHub is a web-first IM-style multi-agent collaboration platform.

## Repository Structure

- `docs/`: product, technical, and collaboration assets
- `frontend/`: React + TypeScript + Vite web workspace
- `backend/`: Spring Boot + MyBatis backend services
- `scripts/`: local helper scripts and future automation entrypoints

## Current Stage

V0.1 initializes:

- documentation assets
- frontend and backend project skeletons
- module boundaries for chat, orchestrator, context, and artifacts
