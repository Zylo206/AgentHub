## 归档原则

- 保留原文件名，便于追溯历史引用。
- 归档后不再出现在 `README.md`、`docs/README.md`、`docs/spec/index.md`、`docs/plans/index.md` 的主导航里。
- 如果某份历史材料仍然需要查阅，只通过这里或子目录索引进入。

## 目录说明

- `collaboration/`：旧的协作协议、模板和状态机说明。

- `submission/`：演示脚本、需求对齐表等提交材料。
- `plan-history/`：已移出主计划入口的历史计划文档。
- `audit/`：一次性审计类文档。
