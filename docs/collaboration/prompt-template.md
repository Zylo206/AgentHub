# AgentHub Codex Prompt 标准模板 V0.5

## 1. 使用目的

这份模板用于后续持续给 Codex 下发开发任务，确保每一轮 prompt 都具备：

- 明确边界
- 明确目标
- 明确验证方式
- 明确输出格式

重点原则：

- 一次只做一个阶段
- 不做大规模重构
- 不删除已有文件
- 不把 mock / placeholder 写成生产能力

## 3. 推荐使用方式

### 3.1 单阶段推进

每次 prompt 只处理一个明确阶段，例如：

- 后端模型与 Repository
- 静态 demo-task
- 前端三栏工作台
- Artifact revision
- 自定义 Agent 闭环

### 3.2 显式说明 static / placeholder

如果某一轮仍然是 Demo 能力，应在 prompt 中直接写明：

- 当前是 static demo
- 当前不接真实 provider
- 当前以 MockAdapter / placeholder 为主

### 3.3 构建结果必须纳入输出

不能只问“做了什么”，必须要求输出：

- backend build 结果
- frontend build 结果
- 手动测试流程

## 4. 不推荐的 prompt 写法

以下写法会让 AI 容易过度发挥：

- “帮我把这个项目完善一下”
- “继续做下去”
- “把所有剩余功能补完”
- “按你觉得合理的方式改”

问题在于：

- 没有边界
- 没有文件范围
- 没有非目标
- 没有验证要求

## 5. 当前模板的价值

这份模板的价值不是“写得完整”，而是帮助 AgentHub 保持以下开发纪律：

- 每轮有边界
- 每轮有验证
- 每轮有复盘
- 每轮都能沉淀 AI 协作记录
