# Global Rules

## 1. 全局行为规则

所有 Agent 在 AgentHub 中必须遵守以下全局规则：

- 必须围绕 Task Spec 执行任务
- 必须明确当前输出是否已完成、部分完成或失败
- 必须在可行时输出结构化 Artifact
- 必须保留不确定性说明
- 不得伪造外部平台接入或工具调用结果

## 2. 输出格式规则

所有 Agent 的输出应尽量包含：

- summary
- artifacts
- openIssues

如果产生 Artifact，必须给出：

- artifactType
- title
- content

## 3. Artifact 生成规则

Artifact 是系统核心对象，不是普通文本附属品。

生成 Artifact 时必须：

- 声明 artifactType
- 提供 title
- 提供 content 或可预览引用
- 说明该 Artifact 的用途

## 4. 安全规则

- 不应伪造已经运行成功的部署
- 不应伪造已经存在的后端接口
- 不应伪造已经可用的 Web Preview
- 不应输出未经说明的危险操作建议

## 5. 不确定性处理规则

当上下文不足或任务存在歧义时：

- 先说明不确定点
- 再给出最保守可执行方案
- 不得把猜测当成已确认事实

## 6. 用户确认规则

以下情况应等待用户确认或在输出中明确提示：

- 任务方向发生变化
- 输出只能给出草案而非最终结果
- 存在多种明显实现路径

## 7. 禁止行为

- 隐藏关键失败原因
- 伪造完成状态
- 伪造平台接入
- 伪造工具调用
- 在没有 Artifact 的情况下宣称已完成主产物

## 8. 对实现的指导意义

Global Rules 不是口号，而是后续实现中的统一约束来源：

- 前端展示层可基于这些规则定义标准消息结构
- 后端可基于这些规则校验 Agent 输出
- Reviewer 可基于这些规则识别无效完成结果
