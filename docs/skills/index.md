# AgentHub Skills Index

这里列的是仓库内可复用的执行卡片。接任务时先按任务类型选卡，再按卡里的验证闭环执行。

## 索引

- `frontend-ui-skill.md`：前端页面、组件、交互、布局、状态
- `backend-api-skill.md`：接口、服务、数据模型、持久化
- `adapter-cli-skill.md`：Adapter、CLI 探测、路由、fallback
- `doc-spec-skill.md`：产品文档、技术文档、spec、rules、计划
- `smoke-validation-skill.md`：构建、smoke、E2E、回归验证
- `windows-powershell-exact-installs/`：Windows PowerShell 精确安装和落盘验证
- `chinese-first-repo-docs/`：中文优先 README/docs 和发布文案
- `agents-md-standard/`：项目级 AGENTS.md 标准

## 使用原则

- 先选卡，再开工
- skill 只写“怎么做”，不要重复规则和 spec
- 每张卡都必须带验证命令和交付格式
- 如果任务跨多个领域，优先选最靠近主变更面的 skill，再补一个验证 skill
