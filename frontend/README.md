# Frontend Skeleton

React + TypeScript + Vite workspace for AgentHub.

## Main Areas

- `src/app/`: app bootstrap and providers
- `src/layouts/`: workspace layout
- `src/pages/`: page-level entries
- `src/features/`: business modules
- `src/components/`: shared UI components
- `src/services/`: API and stream clients
- `src/stores/`: Zustand stores
- `src/types/`: shared frontend types
- `src/utils/`: utility helpers
- `src/styles/`: global styles
